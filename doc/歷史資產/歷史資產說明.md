# 歷史資產說明

本目錄保留舊版設計與操作背景，不是目前 Java 專案的執行手冊。

| 類型 | 定位 |
| --- | --- |
| Python | 舊版 ETL、FastAPI、Streamlit 與文件工具的行為紀錄 |
| Maven | Java 初期骨架與依賴規劃，現行已使用 Gradle |
| 遷移 | 移植前的問題、選型與階段性決策 |
| 架構演進 | 過往架構比較，不表示目前已部署企業 ETL |

目前 Git 不追蹤 Python 腳本、其啟動器或舊文件建置工具。文件提到的 scripts、schema、pom.xml 與舊目錄可能只存在舊版／封存交付；重現前需先取得相應版本，不保證可直接執行。

歷史內容保留當時的命令、計算與限制，不會為了與新版一致而改寫其算法。要操作現行服務，請回 [文件索引](../README.md)；人類文件使用中文檔名，AI 設計／遷移紀錄維持英文檔名。
