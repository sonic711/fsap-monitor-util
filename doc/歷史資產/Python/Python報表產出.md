## 1. 程式定位
`step2_report.py` 是自動化系統的最終產出階段。它負責連接實體 DuckDB 資料庫，加載預先定義好的視圖與工具函數，並根據 `03_sql_logic/reports` 下的 SQL 指令，自動運算出維運人員所需的各項指標。

---

## 2. 核心功能亮點

### 自動化目錄管理
每次執行時，程式會根據「當前時間」自動建立一個獨立的工作目錄（格式：`YYYYMMDDHHMM`），確保：
- **歷史可追溯性**：不同時間點產出的報表不會互相覆蓋。
- **結構清晰**：同一批次的報表成果會被整齊地收納在一起。

### 多格式同步產出 (Excel + CSV)
為了兼顧「管理展示」與「資料分析」的需求，程式會同步產出：
1. **彙總 Excel 報表**：將所有查詢結果整合進單一 Excel 檔的不同分頁中，並自動進行單元格寬度優化。
2. **獨立 CSV 檔案**：針對每個報表項目產生獨立的 CSV 檔。這對於需要快速導入其他系統或進行個別查看的情境非常方便。

### 穩健的 View 同步機制
內建「自動重試依賴」邏輯，即使視圖之間存在複雜的引用關係，程式也能在啟動時自動按正確順序補齊，確保查詢不報錯。

## 3. 運行環境與依賴

### 必要套件
- **pandas**: 用於數據格式化與 Excel 寫入。
- **duckdb**: 提供高效能的數據運算。
- **openpyxl**: 支援現代 Excel 格式 (.xlsx) 的產出。

安裝指令：
```bash
pip install pandas duckdb openpyxl
```

---

## 4. 操作範例

### 執行報表產出
```bash
python3 scripts/step2_report.py
```

### 預期產出物
執行成功後，您可以在 `04_report_output/YYYYMMDDHHMM/` 目錄下看到：
- `維運月度報表_彙總_YYYYMMDDHHMM.xlsx`
- `1.交易量統計-當月.csv`
- `2.1.交易量統計-當月每日-Pivot.csv`
- ...(其餘各項報表的獨立 CSV)

---

## 5. 技術細節
- **路徑自適應**：程式啟動時會自動切換至專案根目錄，確保 SQL 內部的相對路徑（如 `read_csv_auto('00_info/...')`）能被 DuckDB 正確識別。
- **錯誤隔離**：若某支 SQL 報表發生錯誤，程式會跳過該項並記錄錯誤訊息於 Excel 分頁中，不會中斷其他報表的產出流程。
