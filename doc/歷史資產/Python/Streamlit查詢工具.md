# FSAP 維運月報自動化中心 - 知識庫：維運月報查詢工具說明 (Interactive Dashboard)

> 歷史文件：本檔描述保留的 Streamlit 查詢工具。現行 Web UI 使用 Java `serve` 啟動，請參考 [啟動與產生報表](../../人類操作/啟動與產生報表.md)。

歡迎使用 FSAP 維運月報自動化中心。本文件彙整了所有相關技術手冊與操作指南，協助您快速存取資訊。

## 1. 程式定位
`fsap-month-report-db.py` 是一個基於 **Streamlit** 與 **DuckDB** 開發的互動式數據查詢儀表板。它旨在讓維運人員能以極低門檻、高效能的方式，針對 FSAP 數據湖中的海量資料進行 SQL 探索與分析。

---

## 2. 運行環境要求

| 項目 | 需求版本 | 說明 |
| :--- | :--- | :--- |
| **Python** | **3.10 以上** | 建議使用 3.13.x。確保支援現代型別提示與非同步執行。 |
| **Streamlit** | **1.16.0+** | V3.3 使用的 `st.code` 複製按鈕需在此版本以上才能穩定運行。 |
| **DuckDB** | **0.9.0+** | 提供高性能的向量化查詢引擎，支援直接讀取 `.jsonl.gz` 壓縮檔。 |
| **Pandas** | 支援版本 | 用於數據過濾與格式化匯出。 |

> **版本偵測說明**：啟動腳本 `start-fsap-month-report-db.sh` 會自動檢查環境。若使用 Python 3.13.x，系統將判定為符合要求（> 3.10）。

## 3. 核心功能 (V3.3 特色)

### 🚀 一鍵複製至 Excel (TSV 支援)
針對金融維運人員頻繁使用試算表的需求，系統特別設計了 **TSV (Tab-Separated Values)** 格式區塊。
- **操作方式**：點擊結果區黑框右上角的「複製」圖示。
- **效益**：複製後可直接貼上 Excel 或 Google Sheets，**格式與欄位將自動完美對齊**，無需再手動進行資料轉換。

### 🔎 多重獨立查詢 Tab
- 內建 10 個獨立的查詢分頁 (Tab 1 ~ Tab 10)。
- 每個分頁擁有各自獨立的 SQL CMD，適合在進行多指標交叉對比時使用。

### 📦 數據庫結構總覽 (Sidebar)
- 側邊欄自動解析 DuckDB 中的 `information_schema`。
- 即時顯示目前所有的 **資料表 (Tables)** 與 **視圖 (Views)**。
- 點擊展開可查看每個欄位的 **名稱** 與 **資料型別**。

### 📊 多格式數據匯出
- **DataFrame 預覽**：支援分頁與排序。
- **CSV 下載**：自動處理 UTF-8-BOM，確保 Excel 開啟不亂碼。
- **JSONL 下載**：保留完整的資料型別結構，方便二次開發。

### 🕘 查詢歷史與持久化
- 自動紀錄最近 10 筆執行的 SQL 指令及其產出的筆數。
- 勾選「儲存這次查詢」後，下次啟動儀表板時會自動還原該分頁的 SQL 內容。

### 🔄 並發存取優化 (V3.4 更新)
- 改採用「即時連線 (Just-in-Time Connection)」策略：取消全域連線，改為在執行 SQL 的函式中進行連線並在處理後立即關閉。
- 此機制解決了與 API Server (`api_server.py`) 同時存取資料庫時的鎖定衝突 (File Lock)，提升了系統的並發性與穩定性。

## 4. 啟動方式
建議透過專用的啟動腳本執行，該腳本會自動處理環境建立與依賴安裝：
```bash
bash scripts/start-fsap-month-report-db.sh
```
