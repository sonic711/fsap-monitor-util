# FSAP 維運月報自動化中心 - 知識庫：文件建置自動化工具

歡迎使用 FSAP 維運月報自動化中心。本文件彙整了所有相關技術手冊與操作指南，協助您快速存取資訊。

本腳本是一個基於 [Mume](https://shd101wyy.github.io/mume/) (Markdown Engine) 的自動化工具，用於將指定目錄下的所有 Markdown (.md) 文件轉換為高品質的 HTML 報表。

## 1. 核心功能
- **批次轉換**: 自動掃描目標目錄，將所有 `.md` 檔案轉換為 HTML。
- **自動化建立目錄**: 若指定的輸出目錄不存在，腳本會自動建立該目錄結構。
- **樣式整合**: 使用 GitHub 風格主題 (`github-light.css`) 與預設代碼塊主題，確保生成的 HTML 具備極佳的可讀性。
- **離線支援**: 設定為 `--offline` 模式匯出，確保 HTML 檔案具備良好的可攜性。

## 2. 使用方法

### 指令語法
```bash
node scripts/build_docs.js [來源目錄] [輸出目錄]
```

### 參數說明
1. **[來源目錄]** (選填): 存放 `.md` 檔案的資料夾路徑。若未指定，預設為專案根目錄下的 `doc` 資料夾。
2. **[輸出目錄]** (選填): 產出的 HTML 存放資料夾路徑。若未指定，預設與來源目錄相同。

### 執行範例
將 `/doc` 目錄下的文件轉換並輸出到 `/doc/html`：
```bash
node scripts/build_docs.js /Users/weihsinchiu/BlueTech/FSAP-Month-Report/doc /Users/weihsinchiu/BlueTech/FSAP-Month-Report/doc/html
```

## 3. 環境準備
此腳本依賴 Node.js 環境及 `mume` 套件，請確保已執行安裝：
```bash
npm install @shd101wyy/mume
```

## 4. 注意事項
- **檔案處理**: 產出的 HTML 檔名將與對應的 Markdown 檔名一致 (僅副檔名變更為 `.html`)。
- **搬移邏輯**: 若來源目錄與輸出目錄不同，腳本會自動將產出的 HTML 移至指定的輸出目錄中。
- **執行錯誤**: 若指定的來源目錄不存在，腳本會終止執行並給予錯誤提示。

## 5. Mume 引擎深入解析
[Mume](https://shd101wyy.github.io/mume/) 是 Markdown Preview Enhanced 的核心引擎，具備強大的 Markdown 解析能力與擴充性：

- **解析引擎**: 底層整合了 `markdown-it`，提供極高的相容性，完美支援 Mermaid 圖表、KaTeX 公式、Footnotes 與自定義 CSS。
- **匯出彈性**: 透過 `MarkdownEngine` 實例，我們可以精細控制匯出參數：
    - `offline: true`: 將所有 CSS/JS 資源打包進 HTML，確保在無網路環境下依然能正常瀏覽。
    - `runAllCodeChunks: false`: 預設不執行 Markdown 中的代碼塊，確保匯出過程的安全與效能。
- **主題定制化**: 在 `config` 中設定 `previewTheme` 和 `codeBlockTheme`，可輕鬆切換文件視覺風格，適合產生企業級的維運手冊或需求規格書。
