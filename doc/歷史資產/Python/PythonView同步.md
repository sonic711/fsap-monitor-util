# 👓 View 同步工具 (update_views_to_db.py)

> 歷史文件：本檔描述保留的 Python `update_views_to_db.py`。現行 view 同步命令為 Java `sync-views`，請參考 [啟動與產生報表](../../人類操作/啟動與產生報表.md)。

## 1. 程式定位
`update_views_to_db.py` 是一個資料庫邏輯同步工具。它的主要任務是將 `03_sql_logic/views` 下的所有 SQL 視圖定義，持久化地寫入 `05_database/fsap-month-report.duckdb` 實體資料庫檔案中。

這確保了：
- **版本一致性**：實體資料庫內的邏輯始終與 Git 控管下的 `.sql` 原始碼一致。
- **效能優化**：預先定義好的 View 可以讓 Streamlit 儀表板查詢時更快速。

---

## 2. 核心技術亮點：依賴自動解析 (V2.0)

在資料庫開發中，視圖之間常有**依賴關係**（例如：視圖 B 是基於視圖 A 的結果再進行加工）。若單純按檔案名稱排序執行，常會因為「基礎視圖尚未建立」而導致「上層視圖建立失敗」。

本程式透過 **「多輪重試機制 (Retry Mechanism)」** 完美解決此問題：
1. **第一輪同步**：嘗試建立所有視圖。若遇到依賴缺失，該檔案會被標記為 `⏳ [稍後重試]` 並進入待處理清單。
2. **後續輪次**：針對待處理清單再次執行。由於基礎視圖已在上一輪建立，原本失敗的視圖在此輪通常能順利成功。
3. **最終檢核**：若跑完 3 輪仍失敗，則會印出明確的錯誤訊息。

## 3. 運行環境與依賴

### 📦 必要套件
- **DuckDB**: 提供資料庫連接與 SQL 執行能力。

安裝指令：
```bash
pip install duckdb
```

---

## 4. 操作範例

### 執行同步 (建議在專案根目錄執行)
```bash
python3 scripts/update_views_to_db.py
```

### 執行輸出說明
- `✅ [成功]`: 視圖建立成功。
- `⏳ [稍後重試]`: 偵測到依賴關係，程式將在下一輪自動補齊。
- `❌ [最終失敗]`: SQL 語法錯誤或路徑失效，需人工檢查 SQL 內容。

---

## 5. 技術實作細節
- **工作目錄切換**：程式啟動時會自動 `cd` 到專案根目錄。這確保了 SQL 檔案中使用的相對路徑（如 `read_csv_auto('00_info/...')`）能被正確解析。
- **實體連線**：使用 `duckdb.connect('05_database/...')` 進行實體檔案寫入，而非 In-Memory 模式。
