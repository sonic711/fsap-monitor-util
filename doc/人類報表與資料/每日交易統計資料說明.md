# 每日交易統計資料說明

來源是 `FSAP每日交易統計YYYYMMDD.xlsx`，存放於 `01_excel_input/`。Java 依 `fsap.ingest.target-sheets` 選擇分頁，預設處理下列七種：

| 分頁 | 資料內容 | 現行用途 |
| --- | --- | --- |
| `RT_PR_HH24` | 各交易流程的小時交易量、平均處理時間 | 交易量、峰值、排行與月比較報表的主要來源 |
| `MON_LOG` | 系統監控紀錄 | CPU／記憶體報表與監控資料匯出 |
| `RT_CNT` | 每日交易統計 | 保留相關 views 供查詢 |
| `RT_TMSPT` | 交易處理時間 | 保留相關 view 供查詢 |
| `RT_NODE_HH24` | 節點小時統計 | 保留相關 view 供查詢 |
| `BT_CNT` | 批次交易統計 | 轉換保存，目前報表與監控匯出未使用 |
| `ERR_LOG` | 錯誤日誌 | 轉換保存，目前報表與監控匯出未使用 |

Excel 可能另含 `BT_NODE`、`RT_ERR`、`RT_500_TMSPT`，但目前預設不匯入。缺少選配分頁時會略過；若整份檔案都沒有目標分頁，也會跳過。

資料流為：**Excel → ingest 轉成 JSONL.GZ → DuckDB views 讀取 → 產出 Excel／CSV**。並非每個已保存的分頁都會出現在月報。

完整欄位查 [資料結構說明](資料結構說明.md)，補檔與重建查 [啟動與產生報表](../人類操作/啟動與產生報表.md)。分頁或欄位變更時，需同步檢查匯入設定與 SQL；Java 匯入不以 `schema/*.schema.jsonl` 作為驗證規則。
