# 參考資料說明

`<base-dir>/00_info/` 保存主機對照等參考資料。交易名稱與交易類別（`update`／`query`）不在這裡，而是來自每日 Excel 的 `PR_CFG` 分頁（`PR_NAME`、`PR_TPKIND`），見 [ViewSQL說明](ViewSQL說明.md)。

| 檔案 | 對應 view | 用途 |
| --- | --- | --- |
| `CFG_PR_INFO.csv` | `v_cfg_pr_info` | 交易詳細設定，目前報表未直接使用 |
| `prod_eureka_registry_info.jsonl` | `v_prod_eureka_registry_info` | application、IP、port 等主機對照，供監控 views 使用 |

更正主機對照時，維護對應檔案並保留原有欄位格式，再執行 `sync-views` 及受影響的報表或監控匯出。不需修改原始 Excel，也不需重打包 JAR。交易名稱或交易類別有誤時，請由來源（`PR_CFG`）修正。

關聯與算法請查 [ViewSQL說明](ViewSQL說明.md) 及 [報表公式與口徑](報表公式與口徑.md)。
