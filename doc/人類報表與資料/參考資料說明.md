# 參考資料說明

`<base-dir>/00_info/` 保存交易名稱、分類與主機對照資料。來源 Excel 齊全但報表名稱或主機分類不對時，請檢查這裡。

| 檔案 | 對應 view | 用途 |
| --- | --- | --- |
| `PR_INFO.csv` | `v_pr_info` | 交易代碼、中文名稱與 `update`／`query` 等分類 |
| `CFG_PR_INFO.csv` | `v_cfg_pr_info` | 交易詳細設定，目前報表未直接使用 |
| `prod_eureka_registry_info.jsonl` | `v_prod_eureka_registry_info` | application、IP、port 等主機對照，供監控 views 使用 |

更正名稱或分類時，維護對應檔案並保留原有欄位格式，再執行 `sync-views` 及受影響的報表或監控匯出。不需修改原始 Excel，也不需重打包 JAR。

關聯與算法請查 [ViewSQL說明](ViewSQL說明.md) 及 [報表公式與口徑](報表公式與口徑.md)。
