# 基礎參考資料與關聯視圖說明 (00_info)

本專案使用 `00_info/` 目錄下的靜態檔案來作為報表運算的元數據 (Metadata)，透過 SQL 視圖將其載入並供分析使用。

---

## 1. 參考資料檔案說明

| 檔案名稱 | 說明 | 關鍵用途 |
| :--- | :--- | :--- |
| `PR_INFO.csv` | 交易代碼定義表 | 定義交易類型 (`PR_ID`) 與業務分類 (`PR_CATEGORY`)。 |
| `CFG_PR_INFO.csv` | 交易詳細配置表 | 提供更詳細的業務參數配置資訊。 |
| `prod_eureka_registry_info.jsonl` | Eureka 註冊清單 | 紀錄生產環境微服務的實例狀態與資訊。 |

---

## 2. SQL 關聯視圖說明

這些視圖將原始資料標準化，確保在 `03_sql_logic/reports/` 執行複雜查詢時，能夠直接透過 SQL 關聯這些元數據。

### 交易資訊視圖
- **`v_pr_info`**：對應 `PR_INFO.csv`，將中文欄位轉為標準化英文欄位 (`seq_no`, `PR_ID`, `PR_CATEGORY`, `PR_NAME`)，是交易分析報表（如 TOP 6 排行榜）的核心關聯表。
- **`v_cfg_pr_info`**：直接對應 `CFG_PR_INFO.csv`，供需要詳細配置參數的報表使用。

### 環境資訊視圖
- **`v_prod_eureka_registry_info`**：對應 Eureka JSONL 日誌，提供微服務實例的運行時環境清單，供資源監控報表解析主機資訊。

---

## 3. 使用建議
若需新增或修改業務類別 (PR_CATEGORY) 或交易名稱，請優先維護 `00_info/` 下的對應 CSV 檔。維護完畢後，系統會在下次執行 `update_views_to_db.py` 時自動更新這些視圖。
