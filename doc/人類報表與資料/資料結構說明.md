# FSAP Month Report Schema 說明（Schema.md）

## 共通匯入欄位（Meta）

| 欄位 | 中文標題 | 說明 |
|---|---|---|
| `_file` | 來源檔名 | 產生此筆資料的來源檔案名稱（原始匯入檔） |
| `_sheet` | 來源工作表 | 來源 Excel 工作表名稱 |
| `_dt` | 來源檔案日期 | 由來源檔名或路徑推得的日期（YYYYMMDD） |
| `_ingest_ts` | 匯入時間戳 | 資料匯入/寫入 JSONL 的時間戳（epoch seconds） |

## BT_CNT

- **定位**：批次/彙總交易統計（含執行中/暫停等狀態，常作長期趨勢或批次監控）
- **建議主鍵/唯一鍵（推定）**：`CALDY + PR_ID`
- **粒度（Grain）**：彙總

| 欄位 | 中文標題 | 型別 | 說明 |
|---|---|---|---|
| `CALDY` | 營業日期 | STRING | 交易/統計所屬營業日期（多為 MMDD 或 YYYYMMDD，依來源而定） |
| `PR_ID` | 流程代號 | STRING | 交易/批次/監控事件所屬流程代號（如 FAC2FAS、V0009、P94） |
| `PR_NAME` | 流程名稱 | STRING | 流程的中文或描述名稱 |
| `總筆數` | 交易總筆數 | INTEGER | 彙總期間內交易總筆數 |
| `成功` | 成功筆數 | INTEGER | 彙總期間內成功筆數 |
| `失敗` | 失敗筆數 | INTEGER | 彙總期間內失敗筆數 |
| `執行中` | 執行中筆數 | INTEGER | 彙總期間內仍處理中的筆數（尚未完成） |
| `暫時中斷` | 暫時中斷筆數 | INTEGER | 彙總期間內被暫停/中斷待續處理的筆數 |
| `TIMEOUT` | 逾時筆數 | INTEGER | 彙總期間內逾時筆數 |
| `其他錯誤` | 其他錯誤筆數 | INTEGER | 彙總期間內其他錯誤筆數 |
| `_file` | 來源檔名 | STRING | 產生此筆資料的來源檔案名稱（原始匯入檔） |
| `_sheet` | 來源工作表 | STRING | 來源 Excel 工作表名稱 |
| `_dt` | 來源檔案日期 | STRING | 由來源檔名或路徑推得的日期（YYYYMMDD） |
| `_ingest_ts` | 匯入時間戳 | INTEGER | 資料匯入/寫入 JSONL 的時間戳（epoch seconds） |

## BT_NODE

- **定位**：批次節點/步驟執行紀錄（含開始/結束時間、回覆碼與耗時）
- **建議主鍵/唯一鍵（推定）**：`TBSDY + PR_ID + PRN_ID + CALTIME`
- **粒度（Grain）**：明細

| 欄位 | 中文標題 | 型別 | 說明 |
|---|---|---|---|
| `TBSDY` | 本營業日 | STRING | 核心/系統本營業日（Today Business Day） |
| `BBSDY` | 下營業日 | STRING | 核心/系統下營業日（Next Business Day） |
| `PR_ID` | 流程代號 | STRING | 交易/批次/監控事件所屬流程代號（如 FAC2FAS、V0009、P94） |
| `SUB_PR` | 子流程代號 | STRING | 主流程下的子流程/子任務代號 |
| `PRN_ID` | 程序/節點代號 | STRING | 批次流程內的處理程序或節點代號 |
| `BT_NAME` | 批次名稱 | NULL | 批次作業名稱或說明 |
| `SYS_ID` | 系統代號 | STRING | 系統識別代號（例如 FSAP、NCB、FAS 或內部系統代碼） |
| `STATUS` | 處理狀態 | STRING | 處理狀態或結果代碼（成功/失敗/執行中等） |
| `RTN_CODE` | 回覆代碼 | NULL | 系統/主機回覆代碼（成功0000、錯誤碼等） |
| `RTN_MSG` | 回覆訊息 | NULL | 回覆代碼對應的文字說明或錯誤訊息 |
| `EIFM_FG` | 介面旗標 | STRING | 介面/傳輸或執行模式旗標（EIFM_FG） |
| `CALTIME` | 事件時間 | STRING | 事件發生時間（例如開始處理、錯誤發生時間） |
| `FINTIME` | 完成時間 | STRING | 處理完成時間 |
| `TMSPT` | 耗時 | INTEGER | 處理耗時（單位依來源，常見為 ms 或秒） |
| `_file` | 來源檔名 | STRING | 產生此筆資料的來源檔案名稱（原始匯入檔） |
| `_sheet` | 來源工作表 | STRING | 來源 Excel 工作表名稱 |
| `_dt` | 來源檔案日期 | STRING | 由來源檔名或路徑推得的日期（YYYYMMDD） |
| `_ingest_ts` | 匯入時間戳 | INTEGER | 資料匯入/寫入 JSONL 的時間戳（epoch seconds） |

## ERR_LOG

- **定位**：系統/流程錯誤日誌（含步驟、主機、嚴重度，用於鑑識/維運）
- **建議主鍵/唯一鍵（推定）**：`CREATETIME + PR_ID + RTPR_OID + STEP_ID`
- **粒度（Grain）**：明細

| 欄位 | 中文標題 | 型別 | 說明 |
|---|---|---|---|
| `CREATETIME` | 建立時間 | STRING | 紀錄建立時間（TIMESTAMP） |
| `PR_ID` | 流程代號 | STRING | 交易/批次/監控事件所屬流程代號（如 FAC2FAS、V0009、P94） |
| `TX_NO` | 交易追蹤序號 | STRING | 交易/事件追蹤序號（可能為 traceId 或 tx no） |
| `PRN_ID` | 程序/節點代號 | STRING | 流程內部的處理程序或節點代號（例如某一段處理步驟/模組） |
| `STEP_ID` | 步驟代號 | STRING | 流程內部步驟識別，用於定位錯誤發生的步驟 |
| `HOSTNAME` | 主機名稱 | STRING | 發生錯誤的主機/節點主機名 |
| `POST_STATUS` | 送出/處理狀態 | STRING | 錯誤紀錄在送出或處理流程中的狀態 |
| `SEVERITY` | 嚴重度 | STRING | 錯誤嚴重程度（INFO/WARN/ERROR/FATAL 等） |
| `ERR_CODE` | 錯誤代碼 | STRING | 錯誤代碼（系統或應用定義） |
| `MSG` | 訊息內容 | STRING | 錯誤訊息或說明內容 |
| `REMARK` | 備註 | STRING | 補充說明或人工註記 |
| `RTPR_OID` | 流程執行識別 | STRING | 一次流程/交易處理的唯一識別（Process/Runtime OID） |
| `_file` | 來源檔名 | STRING | 產生此筆資料的來源檔案名稱（原始匯入檔） |
| `_sheet` | 來源工作表 | STRING | 來源 Excel 工作表名稱 |
| `_dt` | 來源檔案日期 | STRING | 由來源檔名或路徑推得的日期（YYYYMMDD） |
| `_ingest_ts` | 匯入時間戳 | INTEGER | 資料匯入/寫入 JSONL 的時間戳（epoch seconds） |

## MON_LOG

- **定位**：監控事件紀錄（監控種類、目標、內容與建立時間）
- **建議主鍵/唯一鍵（推定）**：`CREATETIME + MONITOR_KIND + TARGET_IP + TARGET_PORT`
- **粒度（Grain）**：明細

| 欄位 | 中文標題 | 型別 | 說明 |
|---|---|---|---|
| `MONITOR_KIND` | 監控種類 | NULL | 監控事件種類/項目（例如 healthcheck、process、queue 等） |
| `TARGET_IP` | 目標IP | NULL | 監控目標的 IP 位址 |
| `TARGET_PORT` | 目標PORT | NULL | 監控目標的連接埠 |
| `MON_CONTENT` | 監控內容 | STRING | 監控事件內容（訊息、狀態、指標值等） |
| `CREATETIME` | 建立時間 | STRING | 紀錄建立時間（TIMESTAMP） |
| `_file` | 來源檔名 | STRING | 產生此筆資料的來源檔案名稱（原始匯入檔） |
| `_sheet` | 來源工作表 | STRING | 來源 Excel 工作表名稱 |
| `_dt` | 來源檔案日期 | STRING | 由來源檔名或路徑推得的日期（YYYYMMDD） |
| `_ingest_ts` | 匯入時間戳 | INTEGER | 資料匯入/寫入 JSONL 的時間戳（epoch seconds） |
