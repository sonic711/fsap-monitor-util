# 監控資料匯出

此功能提供 Monitor Dashboard 的 CPU、Memory、磁碟與 JVM 趨勢資料，與月報產生是兩條獨立流程。先依 [啟動與產生報表](啟動與產生報表.md) 設定 `fsap` 指令。

```bash
fsap update-monitor-data
```

程式會同步 views 後直接查詢 DuckDB，不需先啟動 Web／API，也不會自動產生或上傳月報。

## 設定與輸出

預設讀取 `config/monitor-data.json`，相對路徑先找 base-dir，再找工作目錄。也可用 `--config /絕對路徑/monitor-data.json` 明確指定。

| 設定 | 實際用途 |
| --- | --- |
| `output_dir` | 輸出目錄；相對路徑以 base-dir 解析，預設 `04_report_output/monitor-data` |
| `tasks[].view` | 查詢來源 view；須具有對應日期、小時、application 與 IP 欄位 |
| `tasks[].filename` | 輸出檔名前綴，每個 task 產生 `.csv`、`.js` |
| `tasks[].type` | 只支援 `daily`、`hourly` |
| `db_path` | 舊格式保留欄位，Java 不使用；DB 由 `fsap.paths.database-file` 決定 |

預設四組輸出是 `daily_data`、`hourly_data`、`jvm_daily_data`、`jvm_hourly_data`，配置範本見 [monitor-data.json](../../config/monitor-data.json)。CSV 使用 UTF-8 BOM，JS 是同份 CSV 的包裝，不是另一套數據。

## 查詢範圍與限制

- daily：以該 view 最新可用日期往前 10 天為下限，包含下限當日，不是固定最近 10 個日曆日期。
- hourly：以最新可用日期往前 4 天為下限，包含下限當日。
- 每個 task 最多 10000 列，不按月報 target-month 篩選。
- task 有資料時覆寫同名輸出；**沒有資料時跳過，舊 CSV／JS 不會自動刪除**。
- 若自訂 output_dir，不在設定的 report-output-dir 之下，現行 Web 清單與下載未必能看到；Web 預設只讀 `04_report_output/monitor-data/` 對應位置。

## 確認結果

查看 Console 的 `tasks`、`success`、`empty` 與 `failure`，並核對 CSV 內的日期和檔案修改時間。`empty` 表示當次沒有新輸出，不能把磁碟上舊檔當成本次結果。

Web 的 Monitor Dashboard 提供表格搜尋、排序、分頁、TSV 複製、CSV 下載與折線圖。它顯示的是匯出檔，不會自行回資料庫更新；先執行 Update Monitor Data，再刷新頁面。主地／異地月報算法見 [報表公式與口徑](../人類報表與資料/報表公式與口徑.md)。
