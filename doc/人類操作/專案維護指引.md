# 專案維護指引

本文件供修改程式的人使用。執行報表與補檔請看 [啟動與產生報表](啟動與產生報表.md)。

## 啟動與除錯

使用 JDK 17，在專案根目錄執行：

```bash
./gradlew bootRunWeb --offline
```

開啟 `http://localhost:18080/`。Task 已設定資料目錄為 `fsap-month-report-develop`，並開啟可操作模式。首次尚未取得依賴時，先在有網路環境移除 `--offline` 執行，或依 [離線建置](../人類部署與建置/Gradle離線建置.md) 準備倉庫。

Eclipse 的 Gradle Run Configuration：

| 用途 | Gradle Tasks | Arguments |
| --- | --- | --- |
| 啟動 Web | `bootRunWeb` | `--offline` |
| 斷點除錯 | `bootRunWebDebug` | `--offline` |
| 更新 Eclipse 專案資訊 | `eclipse` | `--offline` |

除錯 Task 顯示 `Listening for transport dt_socket at address: 5005` 時，是在等待連線。在 Eclipse 的 `Remote Java Application` 選擇此專案，Host 填 `localhost`、Port 填 `5005`，按 Debug 後服務才會繼續啟動。啟動後 Task 持續執行是正常現象，停止服務用 Eclipse 停止按鈕或 `Ctrl+C`。

## 需求要改哪裡

以下 Java 類別位於 `src/main/java/com/fsap/monitor/`；SQL 位於 `fsap-month-report-develop/03_sql_logic/`。

| 要調整的內容 | 修改起點 | 驗證方式 |
| --- | --- | --- |
| 連線、資料目錄、上傳限制 | 外部 `config/application.yml` | 重啟後執行 doctor、上傳測試 |
| Excel 頁籤與檔名規則 | `fsap.ingest.target-sheets`、`filename-pattern` 設定 | 指定一天 ingest，核對輸出 |
| Excel 型別轉換 | `core/ingest/IngestService` | 核對 JSONL 與來源 Excel |
| 欄位改名、SQL 讀取規則 | `views/*.sql` | sync-views、查詢受影響 view |
| 報表數值與欄位 | `reports/*.sql` | generate-report，核對 Excel 與 CSV |
| 月份預設與參數 | `core/report/ReportParameterDefaultsService`、`ReportGenerationRequest` | CLI 與 Web 同月份比對 |
| Excel 格式、分頁順序 | `core/report/ReportGenerationService` | 開啟 Excel 檢查格式與排序 |
| 監控輸出內容 | `config/monitor-data.json`、相關 view | update-monitor-data，檢查圖表與 CSV |
| Web 按鈕與任務順序 | `templates/query.html`（在 resources 下）、`web/controller/TaskController`、`core/task/TaskExecutionService` | Web 操作及 API 檢查 |
| CLI 指令 | `cli/command/`、`cli/FsapCli` | 指令 help 與實際執行 |
| 下載清單與檔案 | `core/artifact/ArtifactBrowseService`、`web/controller/FileDownloadController` | Web 清單與下載 |
| 依賴版本與離線包 | `build.gradle`、`gradle/offline-maven-repo.gradle` | 重新建置及乾淨環境離線驗證 |

## 修改資料或 SQL 時

1. 先確認 Excel → `02_source_lake` → view → 報表中哪一層需要改動；來源與下游對照看 [每日交易統計資料說明](../人類報表與資料/每日交易統計資料說明.md) 和 [ViewSQL說明](../人類報表與資料/ViewSQL說明.md)。
2. 新增頁籤通常先改設定；只有欄位轉換無法支援時才改 `IngestService`。新欄位會按 Excel 表頭寫入 JSONL，但 view 與報表仍需自行選取。
3. 舊日期已匯入時，用 `ingest --date YYYYMMDD --force` 重建受影響日期。先保留原始 Excel 與資料備份。
4. 重跑 `sync-views`、`generate-report`；修改監控 view 時也要跑 `update-monitor-data`。

改欄位前可查找引用：

```bash
rg '舊欄位名' fsap-month-report-develop/03_sql_logic
```

產報月份預設是「主機日期的上個月」，不由 Excel 檔名推導。報表 SQL 中的 `${...}` 由程式代入，日常更換月份應傳指令參數。

第 8 系列的峰日定義與第 1～6 系列不同；改計算方式前請查 [報表公式與口徑](../人類報表與資料/報表公式與口徑.md)。`8.3` 使用 `v_monthly_transaction_stats`，修改相關口徑時需一起核對。

## 改完如何確認

```bash
./gradlew test bootJar --offline
```

Gradle 成功不代表業務數值正確。請在測試資料副本執行受影響流程，檢查失敗數、`report-params.json`、Excel 分頁與代表性數值。改動 UI 或 API 時，同時驗證對應的 CLI 功能。

Java 或套件變更需要重建 JAR；修改外部設定、資料或 SQL 不需要重打包 JAR。設定修改需重啟；SQL 於下次相關指令執行時讀取。依賴變更後，也需重新產生並驗證離線 Maven 倉庫。
